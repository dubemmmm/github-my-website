01 AI Agents · Multi-Agent Systems

Atrium: Multi-Agent Trip Planning Network

A network of specialist LLM agents that plan a trip together. Each agent runs as an independent FastAPI service; they discover each other and delegate work over the Agent2Agent (A2A) protocol, while each reaches its own tools over MCP.

  • Exposed external tools and data through MCP servers, keeping tool access separate from agent reasoning.
  • Built every agent on the OpenAI Agents SDK, but kept the protocol layer framework-agnostic, so an agent built on a different SDK could join the network over A2A without changes elsewhere.
  • Async Python end to end, so agent-to-agent and tool calls run concurrently.

CodeLens: Agentic Coding Assessment Platform

A browser-based assessment platform that scores how engineers investigate, prompt, verify and decide when to trust AI agents, with assessor, candidate and reviewer flows, all inside one fully instrumented sandbox.

03 Research · Adversarial ML · Security

Defending End-to-End Face Authentication Pipelines

Digital KYC onboarding at banks, fintechs and payment platforms gates identity with a liveness model chained to a face recognition model, and an attacker can fool both in one shot. I built that pipeline, attacked it, and proposed a defense that reads the models’ own internal activations.

  • End-to-end pipeline: a ResNet-18 face anti-spoofing model gating a FaceNet face recognition model.
  • Pipeline-aware attacks against both stages: FGSM, PGD, Carlini-Wagner, and a joint multi-objective PGD that defeats liveness and identity matching at the same time.
  • Internal-activation fingerprinting: a 1,411-dimensional feature vector from intermediate layers flags adversarial inputs before an authentication decision is made.
  • Tested cross-paradigm transferability against DeePixBiS, a depth-based liveness model; extends earlier work on an adaptive multi-stage detector (85–93% detection at 6.4 average forward passes).

06 AI Agents · Developer Tools

Autonomous Multi-Agent Code Reviewer

A CLI that reviews code from four angles at once. Four specialist agents run concurrently, then a fifth aggregator merges everything into one prioritized report with a quality score.

  • Four reviewer lenses: StaticAnalyzer (quality, anti-patterns), SecurityAuditor (OWASP Top 10, injection, secrets, CVE lookup), PerformanceReviewer (complexity, N+1, async misuse) and DocChecker (docstrings, type hints, dead code).
  • All four run with asyncio.gather, so a full four-angle review takes about as long as a single agent call.
  • A ReportAggregator agent deduplicates overlapping findings, ranks by severity and produces a 0–100 score, verdict, executive summary and top 3 actions, enforced with Pydantic schemas.
  • Prints each reviewer’s report, then the aggregated report, and saves a Markdown report; supports Python, JS, TS, JSX/TSX, HTML, CSS, JSON and YAML.
